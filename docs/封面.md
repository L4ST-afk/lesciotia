## 二、题铭《来雪亭铭》

> 罗浮山下雪来未？
>
> 江中有亭，此亭待雪。
> 你飞来一场初雪，洋洋洒洒，
> 而梁架先立，瓦色后施，
> 料落其间，遂成一篇。

当前封面图右侧压的即上述首屏短铭文（英译见 README.en.md 首屏）。六句《来雪亭铭》文本留存于本节后段，与《浮龟铭》《蝶花铭》同式，未上当前封面：

> 亭立江心，
> 雪未至不改梁架，序未通不上瓦色。
> 序通乃上瓦，瓦定乃落雪；
> 雪自外来，落进亭中才成景。
> 像与改分验，无证不出一页。
> 雪至则成景。

六句对着本库六件事，逐句可指认：

| 句 | 指什么 |
|---|---|
| 亭立江心 | 取景方向固定（孤屿东北角望罗浮），不外扩成海报、头像、写实插画 |
| 雪未至不改梁架 | 内容未到先定版式族；`check-layouts.py` 守族与式，旧名不许复活 |
| 序未通不上瓦色 | 结构走不通就不上主题；灰度先过，色后到 |
| 瓦定乃落雪 | 瓦作（主题与材质）先落定，素材才往里落——顺序反了就是拿配色猜内容 |
| 雪自外来，落进亭中才成景 | 素材是别人的，本库只负责把它落成一页页 |
| 像与改分验 | B 出口的「像」与 C 出口的「改」各自验，不拿一边的通过当两边的通过 |
| 无证不出一页 | 每份出件都留自检读数；`check_doc_claims.py` 连文档里的数字也回对磁盘 |
| 雪至则成景 | 落雪到位才成篇；没到位不硬凑 |

## 三、英文跋文（与封面题铭对照）

> The pavilion stands on the islet.
> No snow, no change to the frame; no order, no tile laid on.
> Order first, then tilework; tilework fixed, then the snow.
> Snow comes from without — only inside the pavilion does it become a scene.
> Likeness and editability are tried apart; no page leaves without evidence.
> When the snow arrives, the view is made.

## 四、印制说明

- 题铭用字与正文同一套（`assets/fonts/` 内子集字体）；铭文不再另开字重。
- 铭文压在亮部时用深墨，压在暗部时用暖象牙；两档都要过 `check-theme-colors.py` 的对比度判据。
- 封面属 A 出口（影像），不进 B / C 的 spec。
