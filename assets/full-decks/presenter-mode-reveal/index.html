键位

六个键够用

← →
翻页，也认空格、PgUp／PgDn、Home／End
F
全屏；退出用 Esc
S
开演讲者窗，再按一次关
N
讲稿抽屉，只在你自己那屏出现
B
黑屏，讲到一半要观众抬头时用
G
参考线，验页边距与基线用
这页别念完六行，挑 B 和 G 讲：黑屏是礼貌动作，参考线是自查动作。

演讲者窗

四张可拖的卡

卡一

当前页

与观众屏同源，改一下就同步。

卡二

下一页

提前看半页，接话不慌。

卡三

逐字稿

取 .notes 与 .speaker-notes 两种写法。

卡四

计时

R 归零，超时变色。

四张卡都能拖，位置按你自己的习惯摆；关掉再开会回到上次的排布。

同步

两边只通过一条通道说话

观众屏与演讲者窗各自管键位，翻页、黑屏、换主题都走同一条 BroadcastChannel。

单向出口

状态只从 go(n) 写出去，不在键位里各写一半。

不数 DOM

总览会克隆整页，页数只认初始集合。

深链可用

#/5 直接跳到第五页，预览用 ?preview=5。

这里可以现场演示：在演讲者窗点下一页，观众屏跟着变。

讲稿

稿子永远不上墙

写进 .notes 的文字在放映时一律不显示，只有演讲者窗和 N 抽屉读得到。

判据

选择器表要与取稿逻辑同源。漏一种写法，等于把稿子投在墙上——这类事故只看一眼观众席就知道。

这页有条讲稿，你现在看到的就是它：说明它没有出现在观众屏上。
