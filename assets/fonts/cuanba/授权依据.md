## 本项目怎么用才合规

**只做码位裁剪，不动轮廓。**

`assets/fonts/cuanba/CuanBaTi-Subset.woff2` 是用 `pyftsubset` 按码位表裁出来的子集：

- 141 个汉字，144 KB
- 轮廓数据逐字节未改（`pyftsubset` 只删字形、不改字形）
- 用途：龙华寺主题的标题字（`--ff-title` 首位）

这属于「格式转换 / 子集化」，不是「修改字体或制作衍生版本」——字形设计本身没有任何改动。
如果将来有人想给爨八体加墨点、调字重、改笔画，**那就越线了**，必须换成 OFL 字体。

⚠️ 对比：之前做的「墨点宋」是从思源宋（SIL OFL 1.1）派生的，OFL 明确允许修改。
爨八体不允许，所以它只能原样用。

## 一个必须知道的限制

**爨八体只有汉字，没有拉丁字母、数字、标点。**

实测：ASCII 95 个字符、全角标点 27 个，全部不在 `cmap` 里。

所以 `--ff-title` 里它必须排在前面、且后面要有能接住标点和数字的字体：

```
'CuanBaTi','FahwaWenkai',... ,serif
```

标题里出现「·」「，」「2026」这类字符时，浏览器会逐字回落到后面的字体。
这在视觉上是混排，不是错误——但设计稿里要留意。

## name 表

原字体 `nameID 0 / 13 / 14` **全空**（作者没写版权和许可声明）。
子集已补写：

- `nameID 0`：版权行，含作者、发布渠道、授权方式、来源 URL
- `nameID 13`：中文授权说明，含「禁止修改」条款
- `nameID 14`：授权出处 URL

这是为了让字体文件自身可自证，不是替作者改声明。
