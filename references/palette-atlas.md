# 备选配色图谱（Palette Atlas）

> 2026-11-23 建。**本卷不是主题文件**：`assets/themes/` 里只有 9 件自建瓦作（正本、可交付、有材质图），
> 这里收的是**配色的起手式**——六组经典骨架的 token 值，供临时换气质、或给新主题定调时对标用。
> 一切都照本库的 `:root` 变量名写（`--bg` / `--text` / `--accent` / `--accent-ink` / `--surface-2` /
> `--border` / `--muted`），复制进 `assets/themes/<name>.css` 覆盖对应变量即可生效。
>
> 六组值不是任何上游色板的抄本：只借「骨架关系」（明度阶梯、单 accent、纸色偏暖或偏冷），
> 色值按本库口味重新调过——纸底一律避开纯白，accent 一律压到与底色同一口气里，不抢字。

配套三个通用值（六组共用，换组时一并抄）：

```
--border:  color-mix(in srgb, var(--text) 14%, transparent);
--muted:   color-mix(in srgb, var(--text) 55%, var(--bg));
--surface-2: color-mix(in srgb, var(--surface) 88%, var(--bg));
```

## 二、挑组的四问

1. **投影环境亮还是暗？** 现场灯光差、屏幕反光 → 深底（终端墨）；打印或强光 → 素灰 / 铁线。
2. **内容是数还是话？** 数 → 素灰 / 铁线（网格与等宽数字好读）；话 → 和纸 / 暖刊。
3. **要不要一点彩？** 只要一处 → 六组都满足（单 accent 是本库硬律）；要两处 → 第二色从 `--accent` 往 `--text` 混，
   ⛔ 不新开一个 hue。
4. **和已有 9 件瓦作撞不撞？** 撞了就别新建——直接用瓦作（它们带材质图、带纹理导出、带验收）。

## 三、硬约束（违反即回炉）

- **单 accent**：一页只允许一个强调色相。第二强调只能是同 hue 的明度变化或 `--accent` 与底色的混合。
- **纸底不用纯白**（铁线是唯一例外：它把纯白当「印刷纸」语义，靠墨线立骨）。
- **`--accent-ink` 逐组算**：白字压 accent 必须 ≥ 4.5:1；算不够就换深字，⛔ 不许硬写 `#fff`。
- **明度阶梯至少四档**（`bg` → `surface` → `surface-2` → `border`），否则卡片会粘成一片。
- 新增一组若真交付，就要走完整流程：写 `assets/themes/<name>.css`、加进 `references/styles-unified.md` 的映射、
  同步 `check_doc_claims.py` 的主题计数（9 → 10）、重跑 `check-theme-colors.py`。

`fuzhou-rd` / `longhua-si` / `wanhang-fy`）是**有现实锚点、有材料语言、有母题**的完整皮肤；
