# 交付前质检门（13 条）

**判定原则**：任一页不过 = 整份没过。能自动查的必须跑脚本查（脚本返回值不算数，**看产物**：文件是否真写出来、页数是否真对上）。

## 完没完，只有三种答法

- **能交**：13 条全过，且每条有据——`qa/` 里的截图、脚本打印的页数、或 `build-deck.py` 那份自检输出。
- **不能交**：指出哪一页、哪一条，说清是重做还是降级。
- **没验到**：哪几条没验（例：S 键只在 headless 截了观众页），写清用什么验、什么时候验。

⛔ 「看着挺好」不是结论：**截图看过只算目检**——能抓溢出、错字、对比度；页数三方对齐、单文件无残留链接、C 出口文本真能双击改，这类**结构事实**才算过。
**范围**：B 出口过 ≠ A/C 过；这台机过 ≠ 换浏览器、换主题也过。写结论时把范围带上。

## 组 1 · 通用 11 条（逐页过）

| # | 检查 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 1 | 每页一个信息点，标题是结论不是标签 | 逐页读 `title`：能不能一句话说完这页主张 | 拆页 / 重写标题 |
| 2 | 页码与总页数一致、无漏页 | 数产物页数 vs `outline.md` 的 N；B 出口看每页 `.slide-number` 的 `data-total` | 补页 / 改 `data-total` |
| 3 | 文字不溢出、不被裁 | 逐页截图肉眼过；长标题、表格、代码块是重灾区 | 缩字号 / 拆行 / 换版式 |
| 4 | 字号不低于地板、档位不碎片 | A/B 画布 1920×1080：正文 ≥24px、注释 ≥18px、页码 ≥16px；同角色同字号，相邻半磅碎片档先合并（档位表见 `design-guidelines.md` Type Scale） | 抬字号 / 并档 |
| 5 | 对比度过 WCAG AA；角色色走主题槽 | 正文/背景 ≥4.5:1；贴在 accent 色块上的字必须用 `--accent-ink`，不许硬写白或黑；正文/标题/背景/强调引主题槽，品牌固定色才留 hex（口径见 `design-visual.md`） | 换 token |
| 6 | 图片不拉伸、该留白的留白 | 截图/图表/logo 用 `contain`（`.img-frame.contain`）；照片才 `cover`；看图看两侧是否被切 | 换容器类 |
| 7 | 未声明的占位清零 | grep 产物里的 `lorem` / `示例` / `某某` / demo 人名 → 替换或删除。`TODO(数据)` **允许留**，但必须在交付摘要第 2 行登记（见第 10 条）；没登记的 TODO 一律算不过 | 补真实内容，或登记进摘要 |
| 8 | 讲稿不在正页 | 正页只留观众信息；`这一页讲…`/`Speaker:` 一律进备注 | 移进 notes |
| 9 | 语言与单位一致 | 同一份 deck 不混中英标题；数字单位（万/亿/%/pp）统一 | 统一 |
| 10 | 数字可追溯 | `refs` 里每个关键数字有来源；无来源的标 `TODO(数据)` 并在摘要列出 | 补口径或降级为定性 |
| 11 | 盒里放字，**字墨**要正，不是盒子要正 | 两个中心相减：盒上下界取「非背景像素」，字墨上下界取「深墨像素」（阈值按底色定），偏差须 ≤1px。**行高 1.7 时 CJK 字墨比行盒中心低约 2px**——上下内距给成对称，行盒居中、字不居中，必偏 1.5–2px（胶囊实测：盒心 537.5 / 墨心 539） | 上下内距做差 2px（上少下多，例 `10px / 14px`）；⛔ 别用 `line-height` 手算去配 `height`，也别指望「看着差不多」 |

## 完成标准与产物复用

- 只有拿到真实可访问的产物、且没有待处理问询 / 阻塞项，才算完成；封面图、视频封面不代替本体。
- 同一交付目标优先复用原产物 / 原任务，不因本地上下文变化重复创建；状态不明先回读 / 查询已有件，⛔ 直接重建。
- 逐页状态要分清：已取本地 / 已处理 / 已落库；以响应成功 + 页面标识确认落库，退出码 0 ≠ 业务成功；当前页失败先修当前页，不跳过补后续。

## 能自动化的（优先脚本，别靠眼）

```bash
# B：单文件自检（脚本内建，失败非 0 退出）
python3 {baseDir}/scripts/build-deck.py slide-deck/{slug}/index.html --assets {baseDir}/assets

# B：逐页截图（质检与交付预览都靠它；Chrome 写不出文件时也返回 0，脚本以文件非空为判据）
bash {baseDir}/scripts/render-png.sh slide-deck/{slug}/{slug}-single.html all slide-deck/{slug}/qa

# A：页数三方对齐（脚本会打印页数与合并页数）
python3 {baseDir}/scripts/merge-to-pptx.py slide-deck/{slug}
python3 {baseDir}/scripts/merge-to-pdf.py slide-deck/{slug}

# C：可编辑性（形状层判据；A 出口的合图件在这里必红）
python3 {baseDir}/scripts/verify-pptx-editable.py slide-deck/{slug}/{slug}.pptx
```

## 交付摘要里必须写的三行

1. `质检：13/13 通过（证据：qa/ + merge 打印页数）`，或 `12/13（第 N 条：为什么没过、怎么补）`，或 `未验：第 N 条（怎么验）`
2. `数据占位：N 处 TODO(数据)`（没有就写 0 处）
3. `风格落地：A 精确 / B 近似（哪几维是近似的）`
4. 改版件另写：修改范围、总页数、核验项、未确认点（变更控制口径见 `modification-guide.md`）
