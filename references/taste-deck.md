# deck 的反 AI 腔禁型（从 design-taste-frontend 裁过来）

> **本卷不是第二正本**。完整禁型清单、判定例句与边界都在 `design-taste-frontend/references/ai-tells.md`（跨 skill 只写路径文本，⛔ 不写双链）。这里只做一件事：把那份清单按 **deck 语域**裁剪——哪条照用、哪条要换说法、哪条不适用及理由。
> 用法：做 deck 时扫一遍，**命中一条即返工**，不是风格建议。B 出口交付前与 `qa-checklist.md` 一起过。

## 一、照用（16 条）

| 禁型 | 在 deck 上长什么样 |
|---|---|
| 纯黑底 `#000000` | 封面/章节页爱用纯黑。改 off-black、zinc-950、炭灰 |
| 霓虹与外发光 | 深色 deck 的标题外发光。改内边线或淡染影 |
| 过饱和强调色 | 荧光绿/电光蓝压全场。降饱和，与中性色咬合 |
| 大标题渐变字 | 封面主标题做渐变。⛔ 大字用渐变 |
| 靠字号喊的超大标题 | 层级用字重＋颜色造，不靠字号放大 |
| **三列等宽卡片**（图标＋标题＋一句话） | 这是最典型的 AI 幻灯片排法。改两列错位、非对称网格、或纵向递进 |
| 假完美数字（`99.99%`、`50%`、`1234567`） | 换有机数（`47.2%`、`+1 (312) 847-1928`）；没有真数字就留占位并声明 |
| 空壳动词（Elevate／Seamless／Unleash／Next-Gen／Revolutionize） | 只留具体动词：装、配、上、砍掉 |
| 创业套话品牌名（Acme／Nexus／SmartFlow／Cloudly） | 用例子里真实的、有上下文的名称 |
| 手搓 SVG 图标 | 用成熟图标集；⛔ 自己画一套 |
| div 拼出来的假产品截图 | 用真图/生图，或干脆不放 |
| 假名假头像（John Doe／SVG 蛋形人） | 真实姓名＋真图占位或明确示意 |
| **em-dash（`—`／`–`）** | 可见文本零容忍：标题、眉标、正文、图注、引语署名、按钮全禁；只用 `-`（连字符）与 `−`（数学负号）。范围写 `2018-2026`、`€40-80k` |
| **复述型眉标与副标题**（`WORKSPACE ANALYTICS`、大标题下再解释一遍的软话副标题） | deck 的等价是过渡页英文小标签、封面标题下那句口号。删掉不丢信息就删；真要交代就用一行真实限定（受众／版本／场合） |
| **卡内操作说明与按钮下灰色小字**（「每 5 分钟自动刷新」「点击右上角导出」） | 版面只留结论；刷新口径、导出方式进 `notes` 讲稿，⛔ 不进画面 |
| **圆角框套圆角框／无来由的默认米色底** | 一层容器只装一个对象（内层与父容器同单元就拆）；底色跟着风格键走 `styles-<key>.md` 的 Base Color，⛔ 不用模型的默认暖底 |

## 二、换语域照用（7 条）

| 原句（landing 语域） | deck 等价 |
|---|---|
| 章节编号眉标 `00 / INDEX`、`001 · Capabilities` | 过渡页不拿编号当装饰；要标进度就写真页码「3 / 12」 |
| 图片角标 `01 / 4`、贴图 pill `PLATE · 03` | 图注放图外，一行说清是什么 |
| `Stage 1 / Step 2 / Phase 03` | 直接写动词：「安装」「配置」「上线」 |
| 每个导航项/每行前一个装饰彩点 | 只有**真实状态**（数据截止、样本外、未验）才给点，一节最多一个 |
| 十字线、细网格当装饰 | 只在真的组织内容时画线 |
| 「↓ Scroll to explore」滚动提示 | 网页 deck 的等价品是滚轮/鼠标动画图标，⛔ 不用；翻页键说明写进讲稿 |
| 地名/时间/天气条（`LIS 14:23 · 18°C`） | 封面上的「2026 · 上海 · 内部评审」三联条同理要收；要写就写清版本与受众 |

## 三、不适用（6 条，附理由）

| taste 的条款 | 为什么不套 |
|---|---|
| §0 页面类型判定（landing／portfolio／redesign）、§11 改版协议 | deck 的类型由 8 类 archetype 定，改版走 `modification-guide.md` |
| Core Web Vitals 目标、暗色模式强制 | 单文件 deck 不追首屏 LCP；暗色由主题决定，不强制。⚠️ **reduced motion 仍适用**（B 出口有翻页动效） |
| Inter 字体默认禁令 | deck 字体由主题锁。换成等效纪律：**一份 deck 只用一套字族**，标题正文不许混三种以上 |
| shadcn/ui 定制、Unsplash 占位链接 | deck 不用组件库；A 出口由生图供图，不存在外链占位 |
| 鼠标光标、装饰 SVG 的库选型细节 | 归 `path-b-html.md` 管 |
| 长表格「每行上下双边框」 | 投影下淡行线比斑马纹清楚，deck 表照留行线，⛔ 不套此禁 |

## 四、双正本裁定（density）

`VISUAL_DENSITY`（1 画廊 – 10 驾驶舱）与 `references/dimensions-density.md` 是**同一件事**。

**裁定：deck 语域只认 dimensions 四维；taste 三旋钮（`DESIGN_VARIANCE`／`MOTION_INTENSITY`／`VISUAL_DENSITY`）只在「网页落地页／作品集」语域生效。** ⛔ 一份 deck 里同时用两套变量名——两套并存必漂（禅院塔 §2.6 归口唯一）。

## 五、什么时候回读原卷

- 「这条到底禁不禁」「要判定例句」→ 读 `design-taste-frontend/references/ai-tells.md`。
- 冒出**新形态**禁型 → 先补原卷，再回填本卷的裁剪表。⛔ 只在本卷加，那会变成第二正本。
