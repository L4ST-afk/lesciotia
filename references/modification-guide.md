# 逐页改版指南

**唯一原则：先改 `pages/NN.md`，再让对应出口重新派生。** 直接改产物（图/HTML/pptx）里的字，下次重出就丢。

## 目录

- `改一页` / `加一页` / `删一页`
- `换风格` / `换出口`
- `改已有件：变更控制`（清单 / 执行前确认 / 残留检查 / 样式继承 / 页码漂移）
- `重排规则速查` / `改完必查`

## 改一页

| 出口 | 步骤 |
|---|---|
| A 影像 | ① 改 `pages/NN.md` ② 按新内容重写 `prompts/NN-slide-{slug}.md` ③ 重出该页（`--regenerate N` 或 `N,M`）④ 重 merge |
| B 网页 | ① 改 `pages/NN.md` ② 改 `index.html` 里对应 `<section>` ③ `build-deck.py` 重打包 ④ `render-png.sh` 只截这两页核对 |
| C 可编辑 | ① 改 `pages/NN.md` ② 回 ppt-master 改该页（它的规则：在哪层坏在哪层修）③ 回读核验文本可编辑 |
| A+B | 两边都改，页序与标题必须一致；先改 B 定稿，再同步出图 |

内容大改（换了论点）时同时换 slug：`03-slide-old-claim` → `03-slide-new-claim`。

## 加一页

1. 定插入位置（例：第 3 页后）
2. 建 `pages/04-{slug}.md`
3. 渲染该页（A：新 prompt + 生图；B：新 `<section>` + 打包）
4. **重排 NN**：原 `04…` → `05…`，依次 +1；**slug 不变**
5. 更新 `outline.md` 的页条目与头部页数
6. 重 merge 或重打包
7. 若用 B 出口，同步每页 `.slide-number` 的 `data-total`

## 删一页

1. 删 `pages/NN.md` 与产物（图 / `<section>` / prompt）
2. **重排 NN**：后续依次 -1，slug 不变
3. 更新 `outline.md`（删条目 + 改页数）
4. 重 merge / 重打包

> 删页最容易漏 `data-total` 和 `outline` 页数——交付前用质检第 2 条兜底。

## 换风格

**不做逐页硬改**，整份重出：

1. 改 `outline.md` 的 `<STYLE_INSTRUCTIONS>`（A）+ `index.html` 的 `data-theme`/`theme-link`（B）
2. A：全量重出图；B：重打包 + 全量截图核对
3. 交付摘要写明"风格已全量替换"

只换 B 的主题、不改 A 时，pages 不动——这是三出口分离的好处。

## 换出口

`pages/` 保持不动，只跑目标出口的渲染步骤：

| 从 → 到 | 要做什么 |
|---|---|
| A → B | 用 pages 的 `layout/points` 组 HTML，`notes` 进 `.notes`；结构可能微调，但内容不变 |
| B → A | 用 pages 的 `visual` 派生 prompts；页序跟 B 对齐 |
| A/B → C | 先看 C 出口的引擎门（见 `path-c-editable.md`），过不了就降级并明说 |

## 改已有件：变更控制

改已有 pptx / 网页稿时，动手前先立一张变更清单：

| 字段 | 记什么 |
|---|---|
| 目标页 / 页面标识 | 操作前当前页码与标识；增删移后页码会漂移，锚点取操作前的标识 |
| 保留项 | 不动的页面、关键数字、模板母版、备注 |
| 替换项 | 哪页哪块换成什么 |
| 删除项 | 明确要删的页 / 块 / 关键词 |
| 不做项 | 本轮明确不改的范围，避免顺手扩范围 |
| 交付口径 | 验收时核对哪些项 |

执行前确认：

- 页码或风格不确定，先确认样页 / 大纲，不凭记忆改。
- 重排、整页覆盖前，留一份可回滚副本。
- 不可逆操作（删除 / 覆盖 / 发布）先展示目标、影响、回滚方式，经明确确认再做。

全稿残留检查（改完必查）：

- 正文、备注、隐藏页、母版、关键词残留都要扫；年份、金额、数量、币种逐项对账。
- 不依据历史页码定位；不声称「已全删除 / 完全无误」，除非覆盖范围已实查。

样式继承：

- 以原模板、母版、相邻同类页为样式来源；新增页先判页型，优先复制兼容布局再换内容，不另起视觉系统。
- 内容过多先精简或换布局，不优先缩字号；可编辑流程用原生对象，不贴整图。

页码漂移：

- 增 / 删 / 移之后，旧页码 → 新页码要重新映射；协同修改时页码可能已漂移，⛔ 拿旧编号直接改。

## 重排规则速查

| 场景 | NN | slug |
|---|---|---|
| 加页 | 后续 +1 | 不变 |
| 删页 | 后续 -1 | 不变 |
| 重排 | 按新位置重编 | 不变 |
| 改内容 | 不变 | 论点变了才换 |

## 改完必查

- [ ] `pages/` 份数 = `outline.md` 页数 = 产物页数
- [ ] `NN` 连续无空号、slug 无重复
- [ ] A：`prompts/` 与 `pages/` 一一对应，没有孤儿 prompt
- [ ] B：`build-deck.py` 自检通过；每页 `data-current`/`data-total` 正确
- [ ] C：文本仍可编辑、备注仍在
- [ ] `outline.md` 头部页数与实际一致
- [ ] 质检 13 条重跑一遍（至少过第 1/2/3/7 条）
