# 外部样本实测：利兄原创PPT（200 页版式库 + 50 套模板 1011 页）

这份文件记的是**量出来的数**，不是观感。来源是第三方创作者「利兄」的原创 PPT 素材库
（`~/Desktop/利兄原创PPT`，1.5 GB，含 `PPT版式库（利兄原创）.pptx` 200 页 + 50 套模板共 1011 页）。

**只抽比例与档位，不抄图、不抄配色、不搬文件。** 数值是统计量（众数/中位数），不是任何一页的具体参数。

## 怎么量的

用 officecli 起（`view stats` 看总量、`view screenshot --grid` 出 200 页拼图），
再对 slide XML 做逐形状解析：坐标/尺寸换成画布百分比、字号按 pt 归桶、线宽/圆角/行距按 val 归桶。

- 画布 **12192000 × 6858000 EMU** = 13.333 × 7.5 in = **960 × 540 pt** @16:9
- 版式库：200 页 / 9108 形状 / 平均每页 47 个形状（中位 28.5，最多 680）
- 模板库：50 套 / 1011 页 / 字体前三：思源黑体 CN Bold·Light·Normal（526/504/382 次）

## 换算：1920×1080 画布上 **1pt = 2px**

960pt 画在 1920px 上，所以 `px = pt × 2`。下面所有「px」都指 1920 画布里的像素。

## 档位：真件只用 7 档，不是一条长阶梯

1011 页里每页出现过的字号（按页计）：

| pt | px | 出现页数 | 干什么 |
|---|---|---|---|
| 32 | 64 | 517 | **页标题**（众数；34 页用 36、98 页用 40 是封面） |
| 24 | 48 | 431 | 章节名、卡片组标题 |
| 20 | 40 | 440 | 卡片标题、表格首行 |
| 18 | 36 | 762 | 短标签、目录项、要点单行 |
| 16 | 32 | 359 | 正文段落（长段落里 16pt 有 96 处） |
| 14 | 28 | 364 | **密排正文主力**：≥40 字的长文本里 14pt 出现 296 次，最多 |
| 12 | 24 | 214 | 图注、页脚、来源行 |

另有**特大数字一档**：66 / 72 / 80 / 115 pt（132 / 144 / 160 / 230 px），只给“一个数说话”的页。

层级比不是均匀的：32→24 是 **1.33**，24→20 是 **1.2**，20→14 是 **1.43**。
所以真件的“层级感”来自**少档位 + 大跳步**，不是来自字号多。

> 对照我们改前：72/54/32/22/24/14/13 —— 顶部 72→54 是 0.75 倍（对），但 54→32 掉到 0.59、
> 32→22 掉到 0.69，最下面 13px(6.5pt) 直接跌破投影下限。**阶梯断在中段和最下段。**

## 几何

| 量 | 结果 | 我们改后 |
|---|---|---|
| 页左边距 | 众数 **6%**（431 次），其次 7%/8% | 112px = 5.8% ✓ |
| 页上边距 | 众数 **6–7%**（552 次） | 72px = 6.7% ✓ |
| 标题块宽度 | 中位 20%，p25–p75 13–32% | 由族页控制 |
| 并排卡片栏数 | **4 栏 123 次 / 3 栏 102 / 2 栏 79 / 5 栏 18** | g2/g3/g4 已在，三栏是主力 |
| 圆角 | `roundRect adj=50000`（全胶囊）1257 次，其次 41.9%、88% | 胶囊与 `--radius-sm` 都在 |
| 描边 | **无描边 2112 次 ≫ 1pt 662 ≫ 2pt 173** | 卡片默认 1px 细线：比真件重一点，可接受 |
| 行距 | **100%（7130 次）**，130% 288，90% 253 | 正文 1.6 → 偏松，见下 |
| 形状语言 | 椭圆 3102、矩形 2451、直线 653、圆角矩形 640 | 圆点+细线是主要装饰语汇 |
| 主色 | 黑白为主；彩色只出现 1–2 个（C13F3C / 026AFF / 9B0D14 / 0EAAA2） | 主题各自一个 accent ✓ |

**行距这条要单独说**：真件正文是单倍行距（100% ≈ 1.2），视觉上却“疏”，因为它靠 6% 页边距和少字。
我们用 1.7 行距去补“疏”，结果 12pt + 1.7 看起来像 Word 文档缩到一页里。
改法是把字号抬上去、行距收到 1.6，疏朗感交给页边距——不是把行距调到 1.8。

## 我们照做了什么（2026-11-23，v1.2.35）

1. `assets/base.css` 立 `--t-*` 九档阶梯：`hero 200 / display 144 / h1 80 / h2 64 / h3 48 / h4 40 / body 32 / body-sm 28 / cap 24`（对应 100/72/40/32/24/20/16/14/12 pt）。
   族页与主题一律引用 token，**不再出现裸 px 字号**。
2. 正文 24→32（12→16pt），密排 28（14pt），图注页脚 24（12pt，投影下限）；
   标题 54→64（32pt），卡片标题 32→48（24pt），副标 22→40（20pt）。
3. 页边距 96→112px（6%），行距 1.7→1.6。
4. 9 套主题里 191 处字号覆盖全部吸附到同一阶梯——**主题管颜色与装饰，不再各自开一套字号**（原来有 92/68/44/30 与 80/64/48/40 两套并行，同一个 `h2` 在两个主题下差一档）。
5. 装得下闸 `scripts/check-fit.py`：字号一抬，装不下是必然后果，靠肉眼翻 17 族 × 几十段不现实，改成 headless Chrome 逐段量 F1 越界 / F2 被裁 / F3 横向溢出。

## 不照做的

- **不搬 200 页的版式**。那些页是“一页一主题”的成品，不是骨架；我们的 17 族是按信息结构分的，照搬会退回到 36 个单页。
- **不搬配色**。真件主打深墨绿+黑白，那是它的品牌，不是排版概念。
- **不搬满版图压字当默认封面**。我们的 cover 是文字封面，图是可选；这是刻意的差别（导出 PPTX 时文字封面可编辑，压字封面会变成一张图）。
- **卡片 4 栏**：真件 4 栏比 3 栏多，但 4 栏只适合“并列四件同质物”；我们保留 `g4` 不设默认，避免把 4 栏写成习惯。

## 承认的偏差

- 真件正文 14pt + 单倍行距，我们 16pt + 1.6 行距：**更松，单页能装的字更少**。
  这是有意的（投影可读性优先），代价是每页字数预算下降——成稿闸 P4/P8 的字数阈值已随之收紧。
- 统计只看字号的“出现频次”，不知道某块字是标题还是标签；用长度分桶（≥40 字）才把“正文”和“短标签”分开，结论依赖这一步。
