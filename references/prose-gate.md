# 成稿闸（把简陋草稿抬到能出片的密度）

> 入口判据、九条红线与改法。主文件只留一句路由，细则在本卷。

## 为什么单开一段

用户手里的东西经常是一段口语：领导让讲讲、上周做了什么、几个数字。直接进 Step 3 出大纲，
结果是「每页都有字，每页都没话」——版式挑不出错，读起来像套话拼盘。本库不生成文字（生成发生在对话里，
写的人就是模型自己），但**必须有一个不签字的判官**：`scripts/check-prose.py`。

三种入口，走的都是这一段：

| 入口 | 怎么进 |
|---|---|
| 只有粗稿 | 照下面三步抬密度，产出 spec → 跑闸 → 出片 |
| 已有大纲 `outline.md` | 把逐页条目拼成 spec（页型 + 标题 + 要点 + 讲稿首句），跑闸 |
| 已有别人的 pptx | `pptx-to-html.py` 审读 → `retext-pptx.py --dump` 取文字 → 改字 → 再跑闸 |

## 三步

1. **拆**：一句一条。把「能帮工厂省人工，效果还行」拆成「三个厂在用」「省的是巡检工时」两条；
   事实、判断、数字分开放——数字必须能指到出处，指不到就降级成「约」或删。
2. **立**：一页一个主张。标题给**对象 + 动作**（「设备数据采集／卡在三处」），不给形容词；
   lede 说**代价或理由**（「拦住推广的不是硬件，是数据」），不许复述标题；要点每条一个证据。
3. **验**：`python3 scripts/check-prose.py spec.json`。红一条改一条，改完再跑，直到 `可以出片`。

## 九条判据

| 判据 | 红线 | 为什么 | 怎么改 |
|---|---|---|---|
| P1 套话 | 命中词表（赋能/闭环/抓手/一站式/全链路/降本增效…） | 这些词不指任何实事，读者拿不到信息 | 换成本来想说的那件事；说不出来就是没有 |
| P2 标题空转 | ≥2 个抽象词，且无数字、专名、动词 | 「价值体系」这类标题等于没标题 | 补对象与动作：谁、做什么、卡在哪 |
| P3 首句复述 | lede 与标题二字重叠 ≥50% | 复述占掉一整行版面，零信息 | lede 改成理由、代价、或反常识的一句 |
| P4 单条超长 | ≥20 字，或句读 >1 个 | 正文已抬到 32px，栏内约 17 字/行，20 字必两行 | 拆两条；或把从句挪进 `notes` 小注 |
| P5 数字无出处 | 有数字但没声明 `source` / `figures` | 汇报里最贵的字是数字，来路不明就是负债 | 补 `"source": "现场台账 2026-10 至 11"` |
| P6 术语无注 | 大写缩写首现，后面没有（中文） | 听众第一眼卡在词上，后面全听不进去 | 首现写成「VOC（挥发性有机物）」；单位缩写豁免 |
| P7 一页多主张 | 因此/所以/这意味着/总之 ≥2 次 | 两个结论挤一页，等于两个都没立住 | 拆页，或删掉弱的那条 |
| P8 太空或太糊 | 正文 <30 字 或 >260 字 | <30 是空页；32px 下 260 字已约 5 行，再多读不完 | 空：补证据；糊：删到一屏 |
| P9 问叹滥用 | `？`+`！` 总数 > 页数 | 陈述里的问叹互相抵消，语气变虚 | 留一处真问题，其余改陈述句 |

豁免口径三条：`kpi` / `end` / `quote` 三类页本来该稀，不判 P8 太薄；计量单位与自解释缩写
（GB/PDF/HTML…）不算 P6；英文 deck 的 P2/P4 按字符数折算（20 字 ≈ 40 字符）。

## 反例与自证

`examples/prose/` 三件：`rough-input.md`（故意留着的口语草稿）、`good-spec.json`（抬密度后，
3 页直接 `export-pptx.py` 出片）、`bad-spec.json`（套话版，应被闸拦下）。

```bash
python3 scripts/check-prose.py examples/prose/bad-spec.json   # 应红：P1/P2/P4/P8
python3 scripts/check-prose.py examples/prose/good-spec.json --strict   # 应全过
```

## 与 ppt-builder 的差别

它有「通读 → 大纲 → 逐页写作 → 编辑审查」的云端流水线，每步调模型；本库不调模型，因为
写这一步在对话里已经发生，再套一层流水线只会把同一段文字解释两遍。它靠正则查「出处/数字/语气」，
本库把这件事做成**可复算的九条**（同一份 spec，谁跑都得同一个结论），并直接接到出片口：
闸不过 `export-pptx.py` 就该被拒。
