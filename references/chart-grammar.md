# 图表判据卷（数据形状 → 图型）

> 2026-11-23 建。**来源与边界**：图型决策法参考了本库 `lieflat-charts`（PolyForm Noncommercial 1.0.0）
> 的选型思路，但**未复制其代码、模板、命名体系或配色**；本卷只记「什么数据该画成什么」的判据，
> 实现全部在 `assets/layouts.css` 与 `assets/layouts/charts.html`（Chart.js 随包 + 纯 CSS 三式）。
> 选型对不上时，别硬套：宁可换图，也别把数据塞进一个不合适的壳。

## 一、先问三句，再选图型

1. **读者要读一个数、比大小，还是看形状？** 读一个数 → 单数字页（`data-stat`，`n=1`）；比大小 → 轴图或点阵；看形状 → 折线/面积。
2. **数据有几个？** ≤8 类目用柱/条；≤100 个可数单位用点阵；100+ 用百分比条或直方图，别把点缩成尘。
3. **有没有时间轴？** 有 → 轴图（柱/线）；多段构成随时间 → 堆叠（本库暂不做 ribbon，改两页讲）。

## 二、判据表

| 数据形状 | 用什么（本库式名） | 不要用 | 硬规则 |
|---|---|---|---|
| 少类目比较（≤8） | `chart-axis`（柱） | 饼、雷达 | 柱从 0 起，**不断轴** |
| 多选题（各项独立 0–100） | `chart-axis`（柱，横排 `bar-h` 更佳） | 饼（加总无意义） | 标注「各项独立，可超 100%」 |
| 占比 / 100% 构成（≤6 段） | `chart-pie`（环形） | 3D 饼、双环 | 段数 >6 换百分比条 |
| 占比 + 小样本（≤100 可数） | `chart-unit`（点阵） | 饼（扇形靠估） | 副标题写单位：「一点＝一人」 |
| 增减分解（≤6 级） | `chart-waterfall` | 堆叠柱（看不出哪步漏） | 正负同轴，期初/期末实心 |
| 两时点对比（≤6 类） | `chart-dumbbell` | 两根柱并排 | 串珠＝真单位，别用双柱假装 |
| 日序列（≤30 天逐日读数） | `chart-axis`（`line`） | 面积图（挡读数） | 点可数、轴不截断 |
| 30–60 天看形态 | `chart-axis`（`line`，可加面积） | 柱（太密） | 只讲形态就别标每日值 |
| 单值进度（0–100%） | `data-stat` + 进度条 | 仪表盘（拟物） | 数值与条长成正比 |
| 多维度打分（同一实体 3–8 维） | `chart-radar` | 多张柱（读不出轮廓） | 维度写全称，不缩写 |
| 二维散点（≤20 点） | 轴图 + 散点（暂用 `chart-axis` 底） | 气泡（面积易误读） | 面积编码要开方 |
| 分布 / 分箱 | 直方图（B 出口暂无，用 `chart-axis` 近似） | 折线（不是分布） | bin 边界要有业务含义 |
| 排名（静态） | `chart-axis`（横排 `bar-h`） | 饼、雷达 | 排序后画，别按字母 |
| 一对一关系/流程 | 不是图表：走 `flow` 族 | 硬画成图 | 结构关系交 `diagram` |
| 层级与从属 | 不是图表：走 `arch` / 树状列表 | 圆环套圆环 | 只比大小才需要面积图 |
| 一个数字占一页 | `data-stat`（`n=1`） | 柱状图（一根柱没信息） | 数字写单位与口径 |
| 年份×数量（整年） | 日历热力（B 出口暂无） | 折线 | 缺实现就明说降级 |

## 三、语法（与瓦作同源，不另开色板）

- **单 accent**：多系列靠「明度即数据」——第 1 系列用 `--accent`，其余向 `--bg` 分级淡出；⛔ 不写死第二份色值。
- **无 3D、无阴影、无渐变填充**（渐变只作整页染层，不做图元）。
- **标题写结论**：写「钱在哪一步没的」，不写「瀑布图」。图型名只出现在 `kicker` 的辅助位。
- **示例数据用固定值**：不写 `Math.random()`，刷新必须长一样（自检与截图才对得上）。
- **数值与视觉严格成正比**：面积编码开方换算；柱不断轴。

## 四、B 出口与 C 出口的差异（必须明说）

| 式 | B 出口（HTML） | C 出口（pptx） |
|---|---|---|
| `chart-axis` / `chart-pie` / `chart-radar` | Chart.js 随包渲染 | **原生 chart part**（`kind=bar/bar-h/line/pie/doughnut/radar`），PowerPoint 里可改数据 |
| `chart-unit` / `chart-waterfall` / `chart-dumbbell` | 纯 CSS 自绘 | ⛔ 无原生等价：导出时**点名拒绝**，不许塞成柱状图 |

降级规矩：C 出口遇到上表后三种，先在对话里说「这一页在可编辑版本里没有等价图表，改柱状图或保留 B 版」，
由人决定；⛔ 不静默换图型。
